Built on Next.js App Router with file-based routing: `src/app/layout.tsx` defines the root HTML shell with Geist fonts and global CSS, while route groups `(landing)` and `(app)` separate the marketing landing page from authenticated app routes. The landing layout composes `Navigation`, `Footer`, and a `SmoothScroll` wrapper around its child sections (`HeroSection`, `FeaturesSection`, `HowItWorks`, etc.). Shared UI components live in `src/components/` (e.g., `WalletConnect`, `SmoothScroll`). Data access is centralized in `src/lib/`: `api-client.ts` exposes typed REST methods against `NEXT_PUBLIC_BACKEND_URL` for claim CRUD and admin operations, and `sui-client.ts` wraps `@mysten/sui`'s `BaseClient` with network selection (`testnet`/`mainnet`) plus explorer URL helpers. Client-only components are marked with `'use client'`. Path aliases (`@/*` → `./src/*`) keep imports clean.
