The root is a pnpm workspace that declares `backend` and `frontend` as workspace packages; `contracts/` lives alongside them but is built separately via the Sui Move toolchain. The three layers communicate through a shared contract ABI: the frontend calls the backend API, which in turn invokes the published Move modules (attestations registry, identity/external-data/fraud schemas, settlement escrow) on Sui testnet using Ed25519 agent keypairs. `.env.example` centralizes all cross-cutting configuration — Sui network/RPC, published package IDs, agent private keys, admin API key, external API secrets, and the BACKEND_URL/NEXT_PUBLIC_* variables that wire frontend to backend.
