Five independent PowerShell v5.1+ scripts under `scripts/`, each targeting a single lifecycle task with no cross-imports between them — they communicate only through the filesystem (`.env`, `.env.example`) and HTTP endpoints.
- `start-localnet.ps1` is the foundation: it checks for the Sui CLI, runs `sui start --force` in a background process (logging to `.sui-localnet-{stdout,stderr}.log`), polls readiness via `sui client active-env`, then publishes the `insurix-schemas` and `insurix-settlement` Move packages from `contracts/`, parsing package IDs from stdout.
- `start-backend.ps1` and `start-frontend.ps1` are standalone entry points that install dependencies via `pnpm install --filter <service>` and launch `pnpm --filter <service> dev` in the project root.
- `dev.ps1` is the orchestrator: it launches localnet as a PowerShell Job, starts the backend as a child process (`Start-Process` with PID tracking), waits for `http://localhost:3001/api/health` to return 200, then runs the frontend dev server in the foreground and tears everything down in a `finally` block.
- `seed-demo.ps1` is a one-shot utility that calls the backend REST API (`/api/health`, `/api/claims`, `/api/claims/:id`) to create a flight-delay demo claim and print its attestation progress.
Dependency direction is strictly outward: scripts depend on external tools (`sui`, `pnpm`, Node) and the running services; nothing inside the repo imports these scripts.
