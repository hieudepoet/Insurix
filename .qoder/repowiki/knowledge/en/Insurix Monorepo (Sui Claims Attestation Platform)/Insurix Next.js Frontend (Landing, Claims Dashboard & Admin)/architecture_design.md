Built on Next.js App Router with file-based routing under `src/app/`. The root `layout.tsx` sets up Geist fonts and global CSS. Route groups separate concerns: `(landing)` renders the marketing site composed of reusable sections (`HeroSection`, `FeaturesSection`, `HowItWorks`, etc.) wrapped in a `SmoothScroll` layout; `claims/` is a client-only layout that wires up `@tanstack/react-query`, `@mysten/dapp-kit` (`SuiClientProvider`, `WalletProvider`) and a dark-themed navigation; `admin/` implements local-storage-based API key gating before rendering its dashboard. Shared UI lives in `src/components/` (`WalletConnect`, `SmoothScroll`). Data access is centralized in `src/lib/`: `api-client.ts` exposes typed REST clients (`claimsApi`, `apiClient`) against `NEXT_PUBLIC_BACKEND_URL`, while `sui-client.ts` wraps `@mysten/sui`'s `BaseClient` with network selection and explorer URL helpers. Path aliases (`@/*` → `./src/*`) keep imports clean.
