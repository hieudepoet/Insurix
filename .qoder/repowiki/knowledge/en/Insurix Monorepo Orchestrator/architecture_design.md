The root declares `backend` and `frontend` as pnpm workspace packages in `pnpm-workspace.yaml`, while `contracts/` lives alongside them but is built independently via the Sui Move toolchain. The three layers communicate through a shared contract ABI: the frontend calls the backend API, which invokes published Move modules (attestations registry, identity/external-data/fraud schemas, settlement escrow) on Sui testnet using Ed25519 agent keypairs. `.env.example` centralizes all cross-cutting configuration — Sui network/RPC, published package IDs, agent private keys, admin API key, external API secrets, and the BACKEND_URL/NEXT_PUBLIC_* variables that wire frontend to backend.
