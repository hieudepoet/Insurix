Run `scripts\dev.ps1` from the repository root to start the full stack (local Sui network + backend + frontend). Before first use, `scripts\start-localnet.ps1` must be run once to publish Move contracts and populate `.env` with `SCHEMAS_PKG_ID` and `SETTLEMENT_PKG_ID`; if `.env` is missing it is auto-copied from `.env.example`. Stop all services by pressing Ctrl+C in the foreground terminal, then optionally `Stop-Process -Id <PID> -Force` for the backend and `Remove-Job -Id <JobId> -Force` for the localnet job.
